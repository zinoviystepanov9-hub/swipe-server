# Swipe-Server

Backend для приложения "Свайп": аккаунты, поиск людей, контакты, сообщения с мгновенной доставкой (Socket.io), реакции на сообщения и заготовка сигналинга под будущие аудио/видео звонки (WebRTC).

Стек: Node.js + Express + MongoDB (Atlas) + Socket.io + JWT-авторизация.

Хостинг: **Timeweb Cloud, App Platform** — российская платформа, не заблокирована ни у одного оператора/провайдера в РФ.

## Шаг 1. База данных (MongoDB Atlas)

Уже настроена в прошлый раз — ничего менять не нужно, база остаётся той же. Просто убедитесь, что строка подключения (`MONGODB_URI`) у вас сохранена — она понадобится в шаге 3.

## Шаг 2. Выложить код на GitHub

Если репозиторий `swipe-server` уже есть — просто обновите в нём все файлы (перетащите новые через "Add file" → "Upload files", подтвердите замену). Если создаёте заново — как раньше: New repository → перетащить все файлы и папки из этого архива (`Swipe-Server`) в корень репозитория.

**Важно:** файлы должны лежать прямо в корне репозитория (`package.json`, `server.js`, `src/...`), а не во вложенной папке `Swipe-Server/Swipe-Server/...` — эта ошибка уже встречалась раньше.

## Шаг 3. Развернуть на Timeweb Cloud

1. Зайдите на **timeweb.cloud** → зарегистрируйтесь (email или через Google/VK).
2. В панели слева найдите **App Platform** (или "Облачные приложения") → **Создать приложение**.
3. Выберите **Backend-приложение** → подключите GitHub (авторизуйтесь, если попросит) → выберите репозиторий `swipe-server`, ветку `main`.
4. Фреймворк — **Node.js / Express** (платформа обычно определяет сама по `package.json`).
5. В настройках окружения (Environment Variables / Переменные) добавьте:
   - `MONGODB_URI` = ваша строка подключения к MongoDB Atlas
   - `JWT_SECRET` = та же случайная строка, что использовалась раньше (или новая длинная случайная строка)
6. Запустите деплой. Первая сборка обычно занимает пару минут.
7. После успешного деплоя Timeweb выдаст бесплатный технический домен вида:
   ```
   https://ваше-приложение.twc1.net
   ```
   Откройте его в браузере — должно показать `{"status":"ok","service":"swipe-server"}`.

**Важный плюс перед Render:** здесь нет "засыпания" сервиса при простое — задержек в 30-60 секунд на первый запрос быть не должно.

## Шаг 4. Передать мне новый адрес сервера

Пришлите новую ссылку (вида `https://....twc1.net`) — обновлю адрес в приложении (сейчас там прописан старый Render-адрес) и пересоберу архив.

## Структура API (для справки)

- `POST /api/auth/register` — `{ login, password, phone?, email?, avatarRes? }`
- `POST /api/auth/login` — `{ loginOrPhone, password }`
- `GET /api/users/me` — данные текущего пользователя (заголовок `Authorization: Bearer <token>`)
- `DELETE /api/users/me` — удалить аккаунт безвозвратно
- `GET /api/users/search?q=...` — поиск людей по логину/телефону
- `GET /api/users/:id` — публичный профиль по id
- `GET /api/contacts` — список контактов
- `POST /api/contacts` — `{ contactUserId }`
- `GET /api/messages` — список бесед с непрочитанными
- `GET /api/messages/:contactUserId` — история переписки
- `POST /api/messages` — `{ toUserId, text }`
- `POST /api/messages/:contactUserId/read` — отметить прочитанным
- `POST /api/messages/:messageId/react` — `{ emoji }` — поставить/снять реакцию

Socket.io: подключение с `auth: { token }`, события `message:new`, `message:reaction`. События `call:offer` / `call:answer` / `call:ice-candidate` / `call:end` — заготовка под будущие звонки.
